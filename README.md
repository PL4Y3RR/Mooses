# Mooses
Tarina alkaa siitä, kun Mooses on paimentamassa appiukkonsa lampaita midianin erämaassa. Hän näkee palavan pensaan ja Jumala kutsuu häntä vapauttamaan kansansa. Tarina etenee Raamatun tarinan mukaisesti ja pelissä on eri kohtauksia ja jokaisessa on omanlaisiaan pikkupelejä, joita pelaajan täytyy suorittaa. Lopussa Mooses näkee luvatun maan.
